🧩 1. Core Features (Complete List)
👤 User (Tenant / Renter)

Register / Login (email, Google, etc.)

Browse boarding houses (list + map view)

Search & filter (price, location, amenities, availability)

View boarding house details:

Photos, description, rooms, pricing

Map location (pinned by owner)

Book / reserve a room

Online payment (GCash, card, etc.)

Booking history & status tracking

Reviews & ratings

Chat with owner

Save/favorite boarding houses

🏢 Business Owner (Boarding House Owner)

Register & subscribe to a plan

Manage boarding houses:

Add/edit/delete boarding house

Pin location on map (Google Maps / Leaflet)

Room (kwarto) management:

Add rooms, pricing, availability

Set max tenants per room

Booking management:

Approve / reject reservations

Track payments

Dashboard:

Earnings, occupancy rate

Messaging (chat with tenants)

Notifications (new booking, payment received)

Plan upgrade/downgrade

🛠️ Admin

Manage users & owners

Manage subscription plans:

Free, Basic, Premium

Set:

Price (monthly/yearly)

Room limits

Feature access

Approve / verify boarding houses

Monitor transactions

Analytics dashboard

Commission/fees control

Reports (earnings, usage)

Handle disputes

💳 Payment Features

Online payments:

GCash

PayMongo

Cards / e-wallets

Subscription billing (monthly/yearly)

Booking payments

Transaction logs

Refund handling
